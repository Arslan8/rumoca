## What remains unresolved

This is a declaration-only census entry, with no enclosing executable model or failing witness. The source declaration was located and retained, but missing a local min is not sufficient: inherited types, intended signed/zero values, usage and guards still need a declaration-specific proof.

## Evidence needed

Resolve the intended parameter domain and enclosing equations; check inherited bounds, final/protected status, guards and aliases. Construct an otherwise-valid source-level witness, establish a clean baseline in a capable engine, then retranslate at the witness and compare with the runtime override. For equality claims use the actual partner value. Do not apply a blanket min>0 fix yet.

## Evidence basis

Exact stable-ID source/execution review from the first exhaustive audit.

## Original claim

`SI.Length` declares no `min` in `Units.mo`, and this declaration adds none of its own. It therefore accepts a negative value, and a negative length is not a geometry. It does **not** claim that any model sets such a value, or that anything fails. This is the weakest tier in this project and the one most likely to contain deliberate choices.
