## Why this is not a verified bug

R2=(k-1)*R1 deliberately gives zero at the default k=1. R2 feeds a Basic.Resistor, whose documented domain includes zero, and there is no reciprocal R2 in this buffer. Rejecting the nominal unity-gain configuration is a false positive.

## Regression action

Correct the detector/adjudicator for this specific semantic case; do not impose a blanket strictly-positive bound on the library declaration.

## Evidence basis

Exact stable-ID source/execution review from the first exhaustive audit.

## Original claim

`SI.Resistance` declares no `min` in `Units.mo`, and this declaration adds none of its own. It therefore accepts a negative value, and a resistance below zero makes a passive element a source. It does **not** claim that any model sets such a value, or that anything fails. This is the weakest tier in this project and the one most likely to contain deliberate choices.
