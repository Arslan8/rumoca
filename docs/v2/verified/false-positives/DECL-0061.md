## Why this is not a verified bug

GcRef is final and explicitly equals zero when PRef<=0; the default PRef is zero. Both DC and induction-machine Core consumers handle this branch by setting core-loss currents to zero. The reported default-value invariant violation is intended lossless behavior, not a failure.

## Regression action

Correct the detector/adjudicator for this specific semantic case; do not impose a blanket strictly-positive bound on the library declaration.

## Evidence basis

Exact stable-ID source/execution review from the first exhaustive audit.

## Original claim

`SI.Conductance` declares no `min` in `Units.mo`, and this declaration adds none of its own. It therefore accepts a negative value, and the reciprocal of a resistance; negative means generation. It does **not** claim that any model sets such a value, or that anything fails. This is the weakest tier in this project and the one most likely to contain deliberate choices.
